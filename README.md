# Sustainable transport app for Madrid

BSc final project at the University of Sussex (2025): a mobile app prototype bringing Madrid's transport options together, shaped by research with users.

## What I did

- Reviewed existing transport services and apps in Madrid
- Surveyed 41 people about how they travel
- Designed a Figma prototype with multimodal route planning and carbon tracking
- Ran two rounds of user testing and improved the design
- Exported the design to React and refactored the code
